# make-knowledge-cards

把一篇文章转换成 5~8 张知识卡片，每张卡片包含标题、核心知识、简明解释、例子或自测问题。

## 一、项目解决什么问题

读长文容易"读完就忘"：文章本身有结构，但读者学完往往记不住具体知识点，回头查又要重读全文。

本项目提供一个 AI 技能（Skill），把文章压缩成一组**自足**的知识卡片：

- 每张卡只讲一个知识点，脱离原文也能读懂；
- 卡片按原文逻辑排序，连起来能复现原文的知识主线；
- 输出结构化，可直接用于复习、讲解或做笔记。

关键约束是**不编造**：卡片内容全部来自原文，信息不足时宁可少出卡，也不为凑数补充原文没有的内容。

## 二、主要功能

| 功能 | 说明 |
|---|---|
| 文章 → 知识卡片 | 把整篇文章切分为 5~8 个独立知识点并逐张成卡 |
| 四段卡片结构 | 每张卡固定含标题、核心知识、简明解释、例子或自测 |
| 自动去重 | 同义知识点、重复强调、同义例子合并为一张卡 |
| 智能定数 | 知识点充足取 5~8 张；文章很短则按实际数量输出并说明原因，不凑数 |
| 逻辑排序 | 按原文顺序或由基础到进阶排列 |
| 语言跟随 | 原文中文出中文卡，原文英文出英文卡，术语保留原文用法 |
| 卡片清单 | 卡片末尾附仅含标题的清单，便于快速浏览 |
| 结果可存盘 | 按要求写入 `.md` / `.txt` 文件，默认文件名 `<主题>-知识卡片.md` |

**输入形式**：用户粘贴的文章正文；本地 `.md` 或 `.txt` 文件。

**明确不支持**：

- 网页抓取（只给 URL 无法处理）
- PDF / docx / epub 等格式解析
- Anki 牌组（`.apkg`、导入用 CSV）导出
- 图形界面、网页或桌面应用

遇到不支持的输入，技能会直接说明原因并请用户改用粘贴正文或转成 TXT/Markdown。

## 三、安装方法

本技能是纯文本技能包，无第三方依赖、无需编译。

**1. 放到技能目录**

个人级（对所有项目生效）：

```bash
cp -r skills/make-knowledge-cards ~/.workbuddy/skills/
```

项目级（仅当前项目生效）：

```bash
cp -r skills/make-knowledge-cards <项目目录>/.workbuddy/skills/
```

**2. 确认目录结构**

```
make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

`SKILL.md` 的 YAML frontmatter 是技能被识别的依据，必须保留 `name` 与 `description` 两个字段和文件开头、结尾的 `---`。

**3. 生效**

新开一个会话即可使用。技能在以下说法出现时自动触发：做知识卡片、生成学习卡片、把这篇文章整理成卡片、提炼知识点、knowledge cards。

**4. 结构校验（可选）**

```bash
python quick_validate.py skills/make-knowledge-cards
# Skill is valid!
```

校验脚本需要 `pyyaml`。若 Python 环境缺少该模块会报 `ModuleNotFoundError: No module named 'yaml'`，换用自带 `yaml` 的解释器即可（macOS / Linux 系统自带的 `python3` 通常已包含）。

## 四、使用方法

**方式一：直接粘贴文章**

```
把下面这篇文章整理成知识卡片：

<粘贴文章正文>
```

**方式二：指定本地文件**

```
用 make-knowledge-cards 把 ./docs/http-cache.md 转成知识卡片
```

**方式三：指定输出文件**

```
把 article.txt 转成知识卡片，保存到 ./out/我的卡片.md
```

未指定路径时，默认写入当前工作目录，文件名为 `<主题>-知识卡片.md`。只会写入 `.md` 或 `.txt`，不生成其他格式。

技能内部按固定六步执行：通读全文 → 抽取知识点 → 合并去重 → 定数量 → 排序 → 写卡片。

## 五、输入输出示例

以下为真实使用记录，输入为 Paul Graham 的英文文章 *When To Do What You Love*（因篇幅此处只摘录要点结构，实际输入为全文）。

**输入**（节选）：

```
When To Do What You Love

There's some debate about whether it's a good idea to "follow your passion."
... So there's something like a midwit peak for making money. If you don't
need to make much, you can work on whatever you're most interested in; if you
want to become moderately rich, you can't usually afford to; but if you want
to become super rich, and you're young and good at technology, working on
what you're most interested in becomes a good idea again.
```

**输出**（节选，实际输出 7 张卡片）：

```
共 7 张卡片 | 主题：什么情况下应该做自己最感兴趣的事

### 卡片 3：赚钱与兴趣只在"双方想要同一件事"时重合

**核心知识**
别人付钱是让你做他们想要的，不是你想做的——除非两者恰好一致。

**简明解释**
如果主要目标是赚钱，通常就无法负担只做自己最感兴趣的事，因为付钱方要的是
他们的需求。有一个明显的例外：当双方想要同一件事时。例如你热爱足球且踢得
足够好，就能靠踢球拿到很高的报酬。

**例子或自测**
例子：热爱足球又踢得足够好的人，可以靠踢球获得丰厚收入——这是双方需求重
合的情形。

### 卡片 6：赚钱存在一个"中等智力峰值"

**核心知识**
不需要多赚 → 随意；想中等富 → 通常不能；想超级富 → 兴趣又变成好主意。

**简明解释**
把前面几点连起来就得到一条曲线：如果你不需要赚多少钱，可以做最感兴趣的事；
如果想变得中等富有，通常负担不起这样选；但如果你想超级富有，且年轻又擅长
技术，做最感兴趣的事就重新成为好主意。

**例子或自测**
自测：按这条曲线，处在"想中等富有"这一段的人会遇到什么？他通常无法负担只
做最感兴趣的事。

卡片清单
1. "follow your passion" 无法用是或否回答
2. 提问本身就隐含了"代替什么"
3. 赚钱与兴趣只在"双方想要同一件事"时重合
...
```

**极短输入的输出**（`tests/fixtures/pomodoro-short.txt`，约 130 字）：

```
共 3 张卡片 | 主题：番茄工作法的时间结构与休息节奏

### 卡片 1：25 分钟是一个不可打断的工作单元

**核心知识**
每个番茄钟内只做一件事，中途不处理任何打断。

**简明解释**
番茄工作法的基本单位是 25 分钟。在这段时间里只专注一件事，遇到打断不处理，
等这一轮结束再说。

**例子或自测**
自测：25 分钟进行到一半来了条消息，该回吗？不该，等这一轮结束。

### 卡片 2：短休息 5 分钟，每四轮换长休息

**核心知识**
一个番茄钟结束后休息 5 分钟，每完成四个延长到 15~30 分钟。

**简明解释**
时间一到立刻停下，休息 5 分钟再进入下一轮。每完成四个番茄钟，把休息时间
延长到 15 到 30 分钟，形成更大的节奏循环。

**例子或自测**
例子：做完第 4 个番茄钟，休息 15~30 分钟，而不是只歇 5 分钟。

### 卡片 3：这个方法的作用是给注意力一个明确终点

**核心知识**
番茄钟的真正机制是给注意力设一个明确终点。

**简明解释**
25 分钟的边界让注意力有了可预期的截止点，因此更容易进入和维持专注。

**例子或自测**
自测：番茄工作法的核心作用是提高单次专注时长吗？不完全是，核心是给出明确
终点，降低启动和维持的难度。

卡片清单
1. 25 分钟是一个不可打断的工作单元
2. 短休息 5 分钟，每四轮换长休息
3. 这个方法的作用是给注意力一个明确终点
```

原文知识点不足 5 个时，输出实际数量并在概览中说明"原文知识点有限，仅生成 N 张"，不会为凑满 5 张而拆散同一知识点或编造内容。
